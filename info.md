# Water Flow Meter

Custom komponenta pro měření průtoku vody v Home Assistant.

## Funkce

- 🚰 Měření průtoku vody v litrech za minutu
- ⚡ Počítání pulzů za minutu
- 💧 Sledování celkové spotřeby vody
- ⚙️ Snadná konfigurace přes UI
- 🎯 Podpora pro libovolný pulzní senzor

## Rychlý start

1. Nainstalujte komponentu
2. Restartujte Home Assistant
3. Přejděte na Nastavení → Zařízení a služby
4. Klikněte na "+ Přidat integraci"
5. Vyhledejte "Water Flow Meter"
6. Vyberte váš pulzní senzor a nastavte parametry
